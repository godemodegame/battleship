# Paper Tile Prompt

## Runtime Asset

`ui-paper-tile.webp` → CSS `--tex-paper`

## Slot

The base sheet under every `.panel` fill, blended beneath the halftone tile.

## Prompt

```text
Create one seamless tileable newsprint paper texture in warm cream #F7EFDD.
Show subtle uneven ink absorption: soft mottling between #F7EFDD and #E9DCC0,
a few faint short fibers, very light speckle, and the slightly uneven tone of
cheap pulp stock. Keep the contrast low so text stays readable on top — the
darkest speckle no more than 8 percent darker than the base. Flat lighting, no
folds, no creases, no torn edge, no shadow, no perspective. 256x256 pixel
source canvas, opaque RGB, perfectly seamless when tiled in both axes.
Original texture, not based on any existing comic, brand, artist, or protected
visual identity.
```

## Negative Prompt

```text
No folds, no crumples, no torn or burnt edges, no coffee stains, no vignette,
no visible seam, no strong contrast, no yellow-brown aging wash, no printed
text, no lines, no watermark, no shadow, no perspective.
```
