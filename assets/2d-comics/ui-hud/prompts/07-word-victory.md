# VICTORY Word Prompt

## Runtime Asset

`ui-word-victory.webp` → replaces the text in `.result.won h1`

## Slot

Game-over card, won state. Displayed roughly 280 px wide inside a cream panel,
so the art must read against paper, not against a dark scene.

## Prompt

```text
Create one isolated 2D comic word sprite containing exactly the text "VICTORY"
as the winning result of a mobile Battleship game. Heavy hand-inked comic
display caps, tilted about 3 degrees counter-clockwise, letters rising slightly
toward the end of the word. Fill amber #FFC63C with a cold-white #FFFAF0 sheen
on the upper third of each letter, a thick near-black #14121C outline, and a
hard flat ink shadow offset down-right with no blur. Add a compact ring of
short ink rays behind the word and a small halftone dot fan in ink blue #2F6FD0
at the lower-left, all attached close to the lettering. Must stay legible on a
cream paper background at 280 px wide. Transparent RGBA, 1024x512 source
canvas, generous uncropped padding, exact spelling "VICTORY", no other text.
Original design, not based on an existing comic, show, game, font, logo,
artist, or protected visual identity.
```

## Negative Prompt

```text
No misspelling, no extra text, no exclamation mark unless drawn as part of the
requested word, no trophy, no medal, no confetti, no neon glow, no chrome
gradient, no 3D extrusion, no background panel, no ship, no water, no
watermark, no cropped outline, no cream-on-cream low contrast.
```
