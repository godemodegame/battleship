# DEFEAT Word Prompt

## Runtime Asset

`ui-word-defeat.webp` → replaces the text in `.result.lost h1`

## Slot

Game-over card, lost state. Displayed roughly 280 px wide on cream paper.

## Prompt

```text
Create one isolated 2D comic word sprite containing exactly the text "DEFEAT"
as the losing result of a mobile Battleship game. Heavy hand-inked comic
display caps, tilted about 3 degrees clockwise, letters sagging slightly toward
the end of the word. Fill hot pink #F8508F with impact red #E8402E on the lower
third of each letter, a thick near-black #14121C outline, and a hard flat ink
shadow offset down-right with no blur. Fracture the E and A with two controlled
crack cuts and let a single painted black smoke tear trail from the final T.
Add a small halftone dot fan in ink at the lower-right, attached close to the
lettering. Must stay legible on a cream paper background at 280 px wide.
Transparent RGBA, 1024x512 source canvas, generous uncropped padding, exact
spelling "DEFEAT", no other text. Original design, not based on an existing
comic, show, game, font, logo, artist, or protected visual identity.
```

## Negative Prompt

```text
No misspelling, no extra text, no skull, no gore, no tombstone, no crying face,
no neon glow, no chrome gradient, no 3D extrusion, no background panel, no
ship, no water, no watermark, no cropped outline, no low-contrast pink on
cream.
```
